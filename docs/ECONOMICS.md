# 运营与学习额度

## 当前状态

原型不收款，不调用外部 AI，不发行真实额度，不结算创作者收益。以下属于待验证的运营设计。

## 分开记录两种价值

内容访问收入用于回报创作者与支持平台服务。AI 对话、语音及生成等使用收入用于覆盖实际服务消耗。用户看到的学习额度应有清楚的可用范围、预计消耗和上限。

创作端生成与预览，和学习端练习，应分别记录。赠送额度需要预算支持；充值以后仍需准备履行未来的学习服务。

## 需要采集的经济数据

每次学习的实际收入，减去模型与语音成本、支付费用、创作者分成及其他随使用变化的服务成本，得到用于覆盖固定运营开支的贡献。项目目前没有实际付费、调用成本或转化数据，不能据此承诺利润。

## 激励原则

奖励可信内容与有效学习。不要仅按生成字数、聊天次数或延长练习时间支付创作者。学习成绩、社区声誉与可消费余额分别记录。

退款、失败调用、重试和结算应有可追溯的规则与账目。具体价格和分成比例在成本试点之后确定，不在演示中虚构。

## 代币的范围

首期研究平台内的消费额度。对外交易的代币具有不同的发行、交易和治理问题，属于独立提案，目前没有决定发行，也没有投资回报承诺。
