# 项目来源与立项说明

立项日期：2026年10月26日。工作名称：Open Learning Books。最终品牌与域名尚未确定。

## 来源

项目最初讨论如何创作《人性的弱点升级版》：将卡耐基及全球相关著作、社会科学与处世经验作为原始资料，加入跨来源比较、批判、原创综合解释和更有效的教学设计。

随后，项目从书稿扩展为数字学习体验：读完一个小节，读者可以提问、回答、作选择、语音表达或参与多轮情境演练。AI 需要按本书的学习目标和评价标准进行专门设计。

进一步形成的平台构想，是让其他创作者也能制作《说话的技巧》《如何与伴侣相处》等作品，共享阅读、创作、教学、发布与运营基础设施。以 GitHub 协作开发，从可运行体验逐步建设开放社区。

## 使命与用户价值

帮助创作者把知识与经验转化为可教可练的作品，帮助学习者形成能够独立使用、迁移到新情境的能力。

服务三类参与者：学习者、创作者，以及软件与教学贡献者。首轮需要分别验证有效学习、可用的创作工具和可持续贡献机制。

## 教学原则

内容与教法共同设计。尊重、诚实、自主判断和可持续合作是编写价值。允许读者合理质疑书中主张，区分事实、解释、研究证据、价值选择与教学案例。

学习效果通过理解、延迟记忆、陌生情境迁移和行动复盘观察。阅读完成、点赞、聊天量或 AI 角色最终同意，都不能独立证明学会。

## 本次立项交付

项目文档、协作规范、分阶段开发路线、内容与教学数据结构、可运行的响应式原型、自动化检查，以及待创建的 GitHub 任务清单。

项目仓库为 https://github.com/kavadream/open-learning-books 。本地代码已准备并接受检查，远端提交和协作任务以仓库的提交记录与 Issues 为准。文档不得将尚未完成的产品功能写成完成。

## 首期边界

首期用一部示范作品验证学习体验，再邀请少量创作者共同完善编辑和发布流程。采用内部学习额度评估使用成本；可交易代币另行研究，不属于首版发行计划。
