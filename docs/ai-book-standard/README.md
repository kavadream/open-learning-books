# AI 书籍转换通用规范

这是 Open Learning Books 的重要通用项目文件，用于后续不同书籍的 AI 转化。当前版本为 **0.1.3-draft**，保留待审草案状态；保存到项目不等于每条新增建议均已正式定稿。

## 从这里开始

1. 阅读[主规范](AI-BOOK-STANDARD.md)，确认原稿、权利及要提供的能力。
2. 为每本书填写[单书适配登记](BOOK-PROFILE-TEMPLATE.md)，记录引用的规范版本。
3. 整理完整原文、学习入口和该书需要的教学材料。
4. 按[验收记录模板](ACCEPTANCE-TEMPLATE.md)分别记录格式、内容、访问、教学行为及学习效果，不以接口成功代替教学效果。
5. 修订先更新本目录并记入[变更记录](CHANGELOG.md)，再按明确范围迁移单书配置。

对于已有10本或更多完成书稿，用[多书转换清单](BOOK-CONVERSION-REGISTER.md)逐本跟进。原文不默认重写，单书配置、版权、版本与验收分别保存；一本书完成不代表其他书完成。

## 权威来源与边界

GitHub 本目录是项目权威来源。Space 文件是同内容阅读副本，后续从本仓库同步，不独立维护另一套规范。各本书的原文、版权及发布版本仍由各自内容仓库管理。

[原型教学契约](../TEACHING_SPEC.md)保留现有原型格式和行为说明；本规范补充跨书转换与验收流程，不代表已经实现自动转换器、真实 AI 服务或全书学习效果验证。

配套模板均为空白待填写，不代表任何书已经验收通过。不同文体可采用不同教学方式，不强制照搬《理解人性》的写作和逐字阅读设置。
