# 多书转换清单模板

模板版本 0.1.0-draft。用于已有10本或更多书稿逐本转化，不预填虚构书籍、日期或验收结果。

每本书一条记录：

- 稳定 book_id 与书名：
- 原文权威来源、语言、固定版次：
- 权利与本轮授权范围：
- 引用的通用规范版本：
- 本书独立适配登记位置：
- 本书教学资料及版本：
- 本书验收记录位置及覆盖范围：
- 当前阶段（待盘点、材料整理、教学设计、测试、待修复、可交付）：
- 已完成能力与未测试能力：
- 下一步与阻断事项：
- 发布目标及已发布版本（如有）：

各书进度独立。不要以清单完成比例替代某一本书的验收，也不要把同一套场景、问题或许可机械复制给所有书。更新通用规范只产生待评估的迁移事项，不自动修改各书原稿或发布版本。
